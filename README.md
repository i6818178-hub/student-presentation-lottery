# 🎯 학생 발표 순서 정하기 추첨기 (Presentation Order Lottery)

교실 및 수업 현장에서 학생들의 발표 순서를 공정하고 흥미롭게 정할 수 있는 **인터랙티브 번호공 뽑기 프로그램**입니다.

## ✨ 주요 기능

1. **물리 엔진 기반 회전 추첨 박스**
   - 1번부터 25번까지의 알록달록한 번호 공들이 원형 챔버 안에서 실시간으로 튕기며 회전합니다.
2. **원클릭 / 스페이스 바(Space) 조작**
   - **스페이스 바 1회**: 공들이 바람을 타고 격렬하게 섞이기 시작
   - **스페이스 바 2회**: 회전이 멈추며 당첨 공 1개가 튜브로 빨려 올라와 화면 중앙에 대형 팝업!
   - **스페이스 바 3회**: 당첨 팝업 확인 후 다음 추첨 준비
3. **중복 없는 자동 순서 기록**
   - 이미 뽑힌 번호는 박스에서 제외되어 다음 차례 추첨 대상에서 자동으로 제외됩니다.
   - 우측 발표 순서판에 `1번째 발표자: O번`, `2번째 발표자: O번` 형태로 실시간 누적 기록됩니다.
4. **리얼한 효과음 & 폭죽 연출**
   - 별도 외부 음원 다운로드 없이 Web Audio API를 활용한 효과음(구슬 굴러가는 소리, 뿅 소리, 팡파레)과 Confetti 폭죽 연출이 포함되어 있습니다.
5. **교실 맞춤 편의 기능**
   - 📋 **순서 복사**: 클릭 한 번으로 모든 발표 순서를 텍스트로 복사
   - ⚙️ **인원수 변경**: 25명 외에도 필요에 따라 2명~60명까지 자유롭게 인원수 조절 가능
   - ⛶ **전체화면 모드**: 전자칠판, 빔프로젝터, TV 화면에 꽉 찬 화면으로 수업 진행 가능
   - 🔊 **사운드 켜기/끄기** 토글

## 🚀 실행 방법

### 방법 1. 브라우저로 바로 실행
- `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등 웹 브라우저에서 바로 실행합니다.

### 방법 2. 윈도우 실행 파일
- `발표순서뽑기_실행.bat` 파일을 더블 클릭하면 브라우저가 자동으로 열립니다.

## 🎮 키보드 조작 안내
- <kbd>Space</kbd> : 공 섞기 시작 / 공 멈추고 추출 / 결과 확인 닫기
- 마우스 클릭으로도 모든 조작이 가능합니다.
